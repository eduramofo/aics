========================================
 COMO INSTALAR O AICS
========================================

PRE-REQUISITO
  - Windows com permissao de Administrador
  - Servico ICS (Internet Connection Sharing) habilitado no Windows

----------------------------------------
 PASSO 1 — CONFIGURAR
----------------------------------------
Abra o arquivo config.txt e ajuste:

  interface=Ethernet 2     <- nome da sua placa de rede PRIVADA (ex: Ethernet, Wi-Fi 2)
  private_ip=10.10.10.1   <- IP que esta maquina tera na rede compartilhada

Para descobrir o nome correto da interface, abra o PowerShell e execute:
  Get-NetAdapter | Select-Object Name, Status

----------------------------------------
 PASSO 2 — INSTALAR
----------------------------------------
De duplo clique em INSTALAR.bat
Aceite o UAC (prompt de Administrador)

O script ira:
  - Copiar os arquivos para C:\AICS
  - Instalar o servico AICS-Service (inicia automatico com o Windows)
  - Adicionar o icone de bandeja ao startup do Windows

NOTA: Nao execute setup.ps1 diretamente — o Windows bloqueia .ps1 por politica
      de seguranca. O INSTALAR.bat contorna isso automaticamente.

----------------------------------------
 PASSO 3 — VERIFICAR
----------------------------------------
Abra o PowerShell e execute:
  powershell -ExecutionPolicy Bypass -File verificar.ps1

Ou abra o verificar.ps1 no Bloco de Notas, copie o conteudo e cole
no PowerShell.

O resultado sera salvo automaticamente em:
  Area de Trabalho\AICS-verificar.txt

Todos os itens devem aparecer como [OK].
Se algum aparecer [X], o texto indica o que falhou.

----------------------------------------
 DESINSTALAR
----------------------------------------
Abra o PowerShell como Administrador e execute:

  Stop-Service AICS-Service -Force
  C:\AICS\nssm.exe remove AICS-Service confirm
  Remove-Item -Recurse -Force C:\AICS
  Remove-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name "AICS-Tray"
